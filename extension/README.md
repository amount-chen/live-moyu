# 后台发送最小验证扩展（开发工具）

这是保留的早期手动验证工具。普通用户请使用项目根目录说明中的完整桌面程序与 full-extension 连接器。此工具本身不判断服务器接受结果。

## 安装（约 1 分钟）

1. 打开 Edge，在地址栏输入 `edge://extensions`。
2. 打开该页面的“开发人员模式”。这是加载本地扩展的开关，与 Codex 的“完整 CDP 访问权限”无关。
3. 点击“加载解压缩的扩展”，选择本项目的 **extension 文件夹**（里面直接包含 manifest.json）。不要选 ZIP 文件或项目根目录。
4. 在 Edge 工具栏的扩展菜单中找到“直播摸鱼 · 后台发送验证”，可以将其固定。

## 每次测试

1. 在 Edge 打开并登录具体 B 站直播间，处理完页面输入框内原有草稿。
2. 在该直播页点击扩展图标：扩展会绑定这个标签页并打开独立验证窗口。
3. 核对窗口内的直播间名称与地址。点击“检查输入区”。此操作不发送任何文字。
4. 选择一个测试场景，输入**你自己选择、适合公开发送到该直播间的文字**。
5. 点击“10 秒后发送一次”，然后在倒计时内执行对应操作：
   - **后台标签页**：在直播所在窗口切换到其他标签页；不要关闭直播页。
   - **窗口遮挡**：切换到 Word、代码编辑器等工作窗口，遮住 Edge。
   - **最小化**：最小化 Edge 的直播窗口和独立验证窗口，保持浏览器运行。
6. 等待约 15–25 秒，再回来检查直播间有无自己的弹幕，以及登录、禁言、频率限制等页面提示。浏览器后台限速可能导致延迟。
7. 回到验证窗口，选择“看到了自己的弹幕”“没有看到”或“无法确定”。重复完成三个场景。
8. 点击“导出测试记录”，把 JSON 文件和页面异常提示发回给开发者。记录不含弹幕正文，但含直播间地址、时间、场景和人工结论；仅在本次浏览器会话保留，退出前请导出。

**“已触发点击”并不等于服务器确认发送成功。** 当前版本只收集页面点击、输入框是否清空、页面是否隐藏/有焦点等线索，并由你人工确认。页面自身回显也不等于其他观众一定看见。后续稳定版仍需验证可靠的发送结果判断。

## 取消与保护行为

- 发送前可点“取消”。关闭验证窗口不会取消倒计时。
- 发送后或超时不自动重发；结果未确认前不能安排下一条。
- 页面刷新后必须重新点击扩展绑定；关闭标签页或跳转直播间后不会向新目标发送。
- 页面已有草稿时拒绝覆盖；按钮不可用时文字可能留在直播页输入框，需你自行处理。
- 扩展后台重启时待处理测试标为未确认，不恢复发送。重新打开浏览器后重新绑定。
- 同时只测试一个直播间。打开多个验证窗口时也共享同一测试任务。
- 本版本用按钮启动延迟测试，回车不发送，中文选词不会触发发送。

## 找不到输入框或发送按钮

自动识别要求唯一可见的 textarea 和“发送”按钮。页面版本、布局或登录状态可能影响识别。

先确认已登录并能手动发弹幕。若提示候选数量不正确，把错误原文和直播页输入区截图发回；不需要提供 Cookie、密码或登录凭据。高级选项可填写开发者确认过的唯一 CSS 选择器；不确定时保持为空。

## 权限与卸载

扩展仅申请 `https://live.bilibili.com/*` 页面访问、当前标签页、脚本注入和会话存储权限。点击扩展图标后才向选定页面注入脚本，不上传日志，不读取账号 Cookie，不直接调用弹幕接口，不模拟桌面按键。设置选择器和正文仅驻留窗口/当前发送任务内存。

卸载前取消待发送任务，然后在 `edge://extensions` 移除此扩展。刷新直播页即可移除已注入的验证脚本，无注册表或桌面程序需要卸载。

## 开发验证

运行 `npm test` 和 `npm run check`。测试使用 Node.js 内置测试工具和模拟页面，无第三方依赖，覆盖防重复、草稿保护、导航/刷新、长度检查、取消和后台重启。模拟测试不能替代真实直播间验证。

完整桌面程序已经实现，见项目根目录的 README。
